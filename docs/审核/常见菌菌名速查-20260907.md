## 使用入口

[直接打开常见菌菌名速查](https://juleyang020-creator.github.io/microbio-study/#/common-names)

也可从页面顶部 **工具 → 常见菌菌名速查** 进入。

### 添加和补全

1. 点击“添加菌名”。
2. 输入部分中文名或拉丁名，从候选中选择，系统补齐库中已有的名称。
3. 在“自定义简写 / 仪器编码”中填写本机使用的简写，再保存。
4. 库中没有的名称可直接手工填写；拉丁名和简写允许暂时留空。

候选只来自本软件已有名称索引与微生物条目，不猜测新名称，不展开无法确定的缩写属名，也不会生成所谓“通用仪器编码”。名称和简写仍需按本机词库核对。

### 从其他界面加入

- 菌种详情页：点击“加入常用菌名”。
- 完整“菌名速查”页面：点击菌名旁的“＋ 常用”。
- 加入后可继续浏览原页面，也可点击“查看名单”集中填写简写。
- 重复加入不会覆盖已有的手填简写。

### 查找与复制

- “名单内搜索”支持菌名、拉丁名和自定义简写，不区分大小写。
- 每条记录分别提供“复制菌名”“复制拉丁名”“复制简写”。
- 保存与复制保留填写内容的大小写和格式。
- 浏览器不允许自动复制时，显示可选中的文本供手工复制，不会假报复制成功。
- 可编辑记录；移除前需要确认。

### 备份与换机

展开“备份与迁移”：

- **导出备份**：下载 JSON 格式的已保存名单。
- **导入备份**：合并到当前名单，重复条目跳过，保留已有简写。
- 最多保存 500 条；导入文件上限为 2 MB。无效文件或合并后超限会明确报错，不部分覆盖。

**名单仅保存在当前浏览器的本站存储中，不自动跨设备同步。** 不同浏览器、不同设备、本地文件版与线上版的数据彼此独立，换用时请先导出再导入。清理浏览器网站数据前也应先备份。

## 实现与数据保护

| 内容 | 位置 | 处理方式 |
|---|---|---|
| 候选与个人名单模型 | `js/common-names.js:20`、`js/common-names.js:166` | 与公共 DB 分开，纯逻辑可直接测试；数据保存在独立本地键中 |
| 工具界面 | `js/app/common-names.js:43` | 表单、补全、筛选、复制、编辑、移除和备份；不用 innerHTML |
| 其他界面的加入入口 | `js/app/common-names.js:23` | 只加入名称资料，不生成仪器简写；重复项不覆盖 |
| 编辑冲突保护 | `js/common-names.js:202` | 保存时比较编辑开始时的原始快照，防止旧标签页覆盖另一页的新值 |
| 名称与简写的关联确认 | `js/app/common-names.js:87` | 名称变化但仍沿用旧简写时，要求明确核对确认；不静默删除手写内容 |
| 异步导入 | `js/app/common-names.js:7` | 导入任务跨页面渲染管理，完成后更新当前活动视图；离开再返回也能看到结果 |

复审发现并修复的事项：

- 🔴 跨标签页旧编辑可能覆盖新简写：增加编辑快照比对，拒绝覆盖并保留草稿。
- 🟡 改手工菌名可能误清手工拉丁名：区分本次自动补全与既有/手工填写内容。
- 🟡 换名后旧编码可能被无提示沿用：新增明确的保留确认，也保护选择候选时的手写简写。
- 🟡 异步导入完成后可能只刷新旧页面实例：改为通知当前活动视图并保留待展示的结果。

以上均已加入失败→修复→通过的回归测试，并经独立复核确认。
