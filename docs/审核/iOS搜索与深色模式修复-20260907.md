## 根据截图定位的调整

### 🟡 手机搜索框紧贴顶部，聚焦后边缘发虚

- 定位：`css/styles.css:2`、`css/styles.css:56`、`css/styles.css:785`，以及 `index.html` 页头。
- 已确认事实：原搜索框与品牌同处第一行。390px WebKit 检查中，输入框距网页顶部仅 8px，使用原生 `appearance:auto`，自定义描边向外扩展。
- 修法：手机改为“品牌 → 搜索 → 导航”三行，搜索上沿实测移至 64px；安全区之外另留间距。输入框使用自绘外观和内描边，保留 44px 触控高度与 16px 输入字号。搜索 DOM 顺序与视觉顺序一致，聚焦前后不切换行数。
- 未作的假设：没有断言截图模糊一定是哪一种 iOS 系统效果；也没有通过强锁页面滚动、阻止触摸、强制关闭键盘来掩盖问题。

### 🟡 黄色标准说明在深色模式下仍使用浅色底

- 定位：`css/styles.css:953`。
- 已确认事实：“CLSI 与 EUCAST 并列对照”仍为 `#fff8e8`，暗色文字对比度约 2.16:1；相关参考/QC 徽章也存在浅色底遗漏。“本页速览”本身已使用正确的深色背景，未对整页文字盲目压暗。
- 修法：对照说明及相关参考徽章使用深棕底，MEC 徽章使用深蓝底；保留语义色与清楚边界。对照说明最终文字对比度 **6.35:1**。同一参考徽章的浅色文字对比度也已校准到合格范围。
- 医学文字、折点值和判读逻辑均未修改。

### 🟡 白底示意图在暗色页面上过亮

- 定位：`css/styles.css:938`、`js/app/detail.js:17`。
- 修法：只给 SVG 示意图添加深色柔和亮度；放大后提供“查看原图亮度 / 恢复柔和亮度”切换。切换不改变图片 URL，不关闭灯箱。
- 保护范围：不反色、不修改 SVG 源文件。菌落、染色等实拍照片不进入滤镜路径，预览与放大均保留原始颜色。浅色模式也不对示意图降亮度。
