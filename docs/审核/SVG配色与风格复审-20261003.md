## 二、🔴 优先解决的阅读风险与改版门禁

> 分级：🔴 = 优先处理阅读风险 / 必守门禁；🟡 = 局部视觉优化；🟢 = 保留或复用。P0 为未来改版前的硬约束，P1 为先做，P2 为样图确认后再推广。这里的红项**不是对医学内容判错**，也不是本次网站换色引入的新故障。

### R1｜小字浅色化已经影响对比，不能靠“更柔和”继续降色阶　**P1**

**位置与证据：**

| 真实位置 | 前景 / 背景 | 原图对比度 | 现有 `.72` 滤镜后估算 |
|---|---|---:|---:|
| `img/resistance-permeability.svg:62`、`:88`；白底 `:7` | `#8c96a2` / `#ffffff` | **3.00:1** | **2.68:1** |
| `img/stain-gram.svg:13`；角标底 `:12` | `#6b7684` / `#eef1f5` | **4.07:1** | **3.39:1** |
| `img/morphology-overview.svg:39`；白底 `:3` | `#2f8f83` / `#ffffff` | **3.91:1** | **3.34:1** |
| `img/stain-gram.svg:107` 中普通次级文字；面板 `:106` | `#5c6672` / `#f5f7f9` | **5.43:1** | **4.28:1** |

**原因：**这些是 9.5 或 12.5 用户单位的文字，不是单纯装饰线；尤其“缺失 / 关闭”的结果标签不应因灰化而退到难读层级。按普通小字 4.5:1 作为工程检查目标，所列配对存在不足；这里只确认这些配对，**不把全部 SVG 宣称为 WCAG 已通过或全部失败**。

**具体修法：**未来仅针对文字节点，关键解释优先用已有 `#33404f`；普通次级说明可考虑已有界面墨色 `#454b54`，不更改全站中性色变量。角标可采用 `#155E56` 字＋`#E2EFEB` 底；形态分组可把文字加深，保留旁边结构图的类别色。**不要改为更饱和的大片彩底，也不要同时重涂菌体、反应液或培养基。**

依据 `color-analysis.json`：`#33404f` 对白底为 10.57:1；`#454b54` 对 `#f5f7f9` 为 8.19:1，现有滤镜后估算 5.71:1。色值计算采用 sRGB 相对亮度；滤镜后值按通道乘 0.72 并取整，实际白底与角标取样也吻合。抗锯齿、渐变及实拍不纳入这些纯色配对结论。

### R2｜“源码字号合格”不等于手机可读，近方 / 竖图灯箱放大不足　**P1，单独于配色 PR 评估**

**位置：**`img/morphology-overview.svg:1`、`:31`、`:89`；`img/biochem-sugar-panel.svg:1`、`:52-66`；`css/styles.css:220-226`、`:239`；`js/app/detail.js:23-29`。

**原因 / 实测：**390px 视口下，抽样图外宽 358px，扣两侧边框后，9.5 用户单位仅相当于 **7.05 CSS px**。形态总览灯箱未旋转，仍约 **7.09px**；糖发酵面板旋转后约 **8.69px**；普通横图革兰染色旋转后可到 **11.36px**。它们不能被统一描述为“点击就明显放大”。桌面总览两列布局的对应小字也仅约 9.22px，详情约 10.25px。

**具体修法：**样图先在实际显示宽度检查文字层级，而非只看 960px 导出图。保留所有医学文字的前提下，用更少的重复容器、分行和留白帮助扫读；若仍太密，单独规划可缩放 / 平移的读图入口或不丢内容的分面图。**不为适配而删除医学限定语，不在本轮改灯箱或 CSS。**

证据：`app-measurements.jsonl`，以及 `app/390-light-morphology-zoom.png`、`app/390-light-biochem-sugar-panel-zoom.png`。

## 三、🟡 有价值的风格优化

### Y1｜品牌仍停留在网站外层；只接入图版的无语义装饰区　**P2**

**位置：**`css/styles.css:15-19`、`:927-939`；`js/app/detail.js:57-60`；`img/landing-tests.svg:11-15`、`img/mechanism-cellwall.svg:10-14`。

**原因：**本轮 SVG 显式绘色声明中，新品牌的 `#155E56 / #E2EFEB / #B9D9D0 / #62BDB3 / #1F5F8B / #80B7DC` 均为 0。图片经外部 `<img>` 加载，页面 CSS 变量不会自动改写 SVG 内的硬编码颜色。**“未使用品牌色”本身不是缺陷**；真实拼版显示中性色图版与青绿外层已经能共存。

**具体修法：**先试一张图，仅把右上分类角标或一处短标题线接入深青绿，标题主体仍可保留现有深墨色。勿给每个面板铺浅青绿，勿把蓝色靶酶误当网站链接而改色。推荐约束：

| 角色 | 推荐 | 约束 / 计算依据 |
|---|---|---|
| 白底 SVG 的少量品牌字 | `#155E56` | 对白底 7.59:1；不因网站进入深色模式就换成浅青绿 |
| 分类角标 | `#155E56` 字＋`#E2EFEB` 底 | 6.42:1；当前 `.72` 后估算 4.71:1，仍需实际渲染复验 |
| 装饰边线 | `#B9D9D0` | 对白底仅 1.51:1，只可用于非必要装饰，不能拿来画关键箭头或菌体边界 |
| 深色宿主控件 | 沿用 `#62BDB3`、底 `#191c21` / `#20242b`、弱底 `#20312F` | 不直接搬进白底图版；`#62BDB3` 对白底仅 2.22:1 |
| 真实链接 | 网站 `#1F5F8B` / `#80B7DC` | 不强制套到不可点击的图中文字或结构编码 |

网站已有中性色与 green / rust / gold 均不在本轮建议的全局改动范围内。

### Y2｜模板感主要来自重复容器与层级，而非所有颜色太粉　**P2**

**位置：**`img/landing-tests.svg:19-20`、`:55-56`、`:98-99`、`:133-134`；`img/landing-biochem.svg:13`、`:33`、`:53`、`:74`、`:96`、`:108`、`:129`。

**原因：**总览多次重复“外部圆角框＋内部白框＋右上胶囊＋底部横条”。全库中性面板 `#f5f7f9` 出现在 153 张，角标底 `#eef1f5` 出现在 133 张；真实拼版与视觉工具意见一致：已经是克制教学图，但密集拼在一起会显得“框中有框”。**不能从圆角或淡色的统计，推导所有框都是多余的。**

**具体修法：**总览样图先把同类内容整理成开放行 / 单层分区，用间距和细分隔替代一层重复容器；保留一级分类和真正的操作步骤边界。页眉角标只保留一处青绿强调，页脚降为中性说明。圆角调整只针对装饰面板，**不改试管底部、菌体形态和其他有含义的几何**。先检查线条功能，再统一同一功能的线宽，不把所有细胞结构都加粗到同一粗细。

## 四、🟢 建议保留的基础

### G1｜有语义的渐变、荧光和培养皿质感应保留　**P0 保留**

**位置：**`img/stain-auramine.svg:5-16`、`:63-81`；`img/media-blood-agar.svg:4-6`、`:20`；`img/biochem-urease.svg:6-8`、`:50`。

**原因：**48 张含渐变，不能统称“装饰过多”。上述荧光、反应变化、培养皿有各自表达任务。血平板原图的多个无覆盖位置实测为 `(170,75,82)`、`(169,75,81)`、`(160,68,75)`；脲酶色带三个位置为 `(233,183,73)`、`(231,159,83)`、`(216,74,122)`，与源码渐变相互印证，不是根据模型猜测存在与否。

**具体做法：**保留这些语义效果；去模板感优先动外围容器，不新增全画布渐变、炫光或阴影，也不批量移除原有渐变。

### G2｜现有深色模式允许返回原亮度，应保留这条观察通道　**P1 保留并复验**

**位置：**`css/styles.css:950-954`；`js/app/detail.js:40-50`。

**原因 / 实测：**默认深色 SVG 为 `brightness(0.72)`，图内白底实际像素从 `(255,255,255)` 变为 `(184,184,184)`，不是变成深色画布。手机抽样灯箱点击“查看原图亮度”后，滤镜确为 `none`、按钮 `aria-pressed=true`。它能协调暗页亮面，却不会自动保证小字对比。

**具体做法：**本轮不动滤镜或白画布；以后优先增强图内文字层级，并保留恢复原图亮度。不得整体反色、加全图青绿滤镜，或把这种处理推广到临床实拍照片。临床色相观察与夜间舒适性的真机表现仍需人工复核。

### G3｜统一字体、标题 / 描述与路径体系可以直接复用　**P2 复用**

**位置：**`img/stain-gram.svg:1-2`、`img/morphology-overview.svg:1-2`、`img/mechanism-cellwall.svg:1-2`；动态映射 `js/view.js:202-216`。

**原因：**164 张在字体、标题 / 描述、画布宽度方面已有共同基础，引用也已覆盖，不存在仅为品牌改色而另建整套文件的必要。

**具体做法：**后续样图尽量保持文件名、viewBox、标题 / 描述和所有医学标签；先以小范围节点名单改装饰，不做 Illustrator 往返导出或全量机械重着色。
