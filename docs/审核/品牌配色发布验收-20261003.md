## 改动范围

本次仅调整界面颜色并同步缓存版本：

## 测试器修正说明

### 🟡 已修：路由回退与自动点击时序

`tools/ui-check.mjs` 的既有测试在连续返回历史时未等待中间路由完成；“输入后在150ms内点击当前条目”又把 Playwright 自动滚动/动作稳定等待计入时间，导致先触发搜索、再发现原链接被移除。

修法：等待各个真实历史路由和对应详情 DOM；对输入防抖取消这个特定断言，在同一浏览器任务中派发输入和点击事件。其他真实点击、键盘和导航流程照常验证。**未修改应用搜索逻辑，也未删减失败断言。** 初次失败日志保留在本地证据目录，最终同步后的运行全绿。

### 🟡 已修：配色对照的状态污染

清理 localStorage 并不能清除单页应用内存中的最近浏览列表，新增路由又会改变主内容滚动位置。配色对照现在用不同 query 强制新文档，清理存储并固定滚动位置；用保存的原 CSS 重新生成同条件基线。修复后208组正文与几何对照全部一致。

### 🟡 已修：检查器失效时必须明确失败

`tools/brand-colors-check.mjs` 现在把缺少对应基线、前后用例集合不一致、重复用例、基线运行报错全部判为失败；读取静态文件成功后才发送200响应，缺失资源返回404，不再重复发送响应头。

`tools/brand-colors-selfcheck.mjs` 显式运行的35项自检全部通过，覆盖基线异常、真实HTTP缺失资源、CSSOM唯一opacity绘制例外与当前208组记录。该文件不使用默认 `.test.*` 命名，避免让原本无依赖的 `node --test` / 发布检查隐式依赖外置Playwright；已取消浏览器环境变量重新运行默认发布检查，200项全绿。
