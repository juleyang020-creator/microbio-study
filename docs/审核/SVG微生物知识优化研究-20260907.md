# SVG 图片中的微生物知识：内容优化研究

日期：2026-09-07；对象：知微静态版当前工作树的图片知识。本文接续视觉审查，但不重复讨论字号、配色和布局。

## 一、结论

**有明确优化空间，而且不只是“再加知识”。最应优先做的是纠正概念错误、恢复被压掉的限定条件，并让图表达的结论强度与证据一致。**

目前一些图片把“帮助记忆的典型现象”压缩成了“可以直接下结论的规则”。图题、箭头、等号、颜色和脚注共同构成知识表达，不能只核对正文中的名词是否拼写正确。

本轮得到 **4 类优先内容问题、5 类严谨性改进点**。其中既有可以直接确认的错误，也有在补足适用范围后可以继续使用的教学简化，二者在下文分别说明。

### 本轮做了什么，没做什么

- 对当前 `img/` 全部 **164 张 SVG** 做文字风险筛查，范围包括 `title`、`desc` 和可见文字；“唯一、其他不、即定、确证、决定”等关键词在 **32 张**中命中。**这是检索命中数，不是错误图片数。**
- 在此基础上，对下文涉及的 **7 张重点图片**进行具体概念和证据核对；同一图片可能包含多个问题。
- 资料包括人卫2025第2版相关章节、CLSI M100 Ed36原始PDF的解释类别定义、EUCAST官方说明、CDC诊断/消毒说明、Adelaide University Mycology和同行评议的概念综述。
- 证据区分：①图片自身的逻辑矛盾；②外部资料支持的订正；③需要限定范围的教学简化；④尚未核验的内容。
- **这不是164张图全部医学陈述、数值和方法条件的逐条认证，也不是随机抽样误差率调查。**未据此计算“准确率”或声称其余图片全部正确。
- 本轮只提出知识层面的修改建议，不修改应用、图像或医学数据，不展开培养、工程改造或其他实验操作参数的优化。

## 二、🔴 优先内容问题

### R1. MIC 示例的数字方向与图示逻辑不一致

**定位：**`img/glossary-ast-terms.svg:17`～`:29`。

**图片实际表达：**

- 管上数字从左至右为 `8、4、2、1`。
- 前两支为蓝灰填色，后两支白色；图中文字却解释为“浊→清分界”，并把 `2` 标成 MIC。
- 如果按该图自身的“白色＝不长”逻辑，右端更低的那一档也“不长”，便不能将左邻那一档称为最低抑制浓度。

MIC强调的是抑制生长所需的最低浓度，而不是不分浓度方向地取“从左边数第一支清亮管”。该定义也得到概念综述支持。[18]

**判定：确定的图内逻辑错误。**这不是字体问题，也不是一个无关紧要的箭头位置问题。

**建议改法：**重排这组示意的浓度方向、浑浊/清亮图例和标记，使三者一致；图内定义改为“在规定试验条件下，达到相应抑制终点的最低药物浓度”。非通用的终点例外交给具体条目，不在术语图中混写。

**特别说明：**此处不是建议把某个真实标本的MIC改成另一数值，也不新增药物折点；需要修的是教学图本身。`img/test-colistin.svg:45`～`:68`的另一组示意在浓度排列、清亮孔和标记之间是自洽的，不能把这里的问题扩大成“所有MIC图都错”。

### R2. “厚壁孢子为白念珠菌独有”不成立

**定位：**`img/media-corn-rice-tween.svg:13`、`:40`、`:63`。

**原文问题：**图中使用“身份证”比喻，又写“其他念珠菌不产生”，并将两种表型同时阳性直接指向白念珠菌。

Adelaide University的都柏林念珠菌条目明确描述其也可有厚壁孢子；因此，“其他念珠菌不产生”不是可接受的概括。[2] 项目自身的 `data/differential.js:1108`～`:1109`也记录了相关共表型。这一次不再只是发现内部矛盾，已有独立来源支持否定该绝对化结论。

**判定：确定错误，同时存在结论过度升级。**

**建议表达：**

> 厚壁孢子是重要的形态学线索，但并非白念珠菌独有；不能仅凭这一特征确认到种。

“典型表现”可以继续画，不必为了补例外把整张图变成鉴别表。关键是删除独有性的暗示，把“提示”与“确认”分开。

### R3. 真菌结构图混入不对应的描述，并沿用过时分类框架

**定位一：**`img/glossary-structure-fungi-virus.svg:48`～`:49`。

在曲霉分生孢子头说明下面，又加上“大分生孢子梭形·小分生孢子链状”。这不是曲霉属的通用结构描述。权威形态资料将其分生孢子头解释为顶囊、瓶梗、可有的梗基及分生孢子的组合。[5]

**建议：**删除这句混入的大小分生孢子概括；按图上实际画出的结构标注。不要把别类真菌常用的鉴别词汇拼接成一个看似“更全面”的曲霉描述。

**定位二：**同图 `:3`、`:102`，将“有隔/无隔”写成“门级分类轴（接合菌 vs 子囊菌）”。

现行本地教材第24章已经明确说明原接合菌门、接合菌纲被撤销，并采用毛霉目等相应分类。这与图中仍把旧分类当成现行二分框架不一致。[29]

**建议：**将“菌丝有隔、少隔等形态观察”与“现代分类位置”分开；旧名称可作为历史检索别名保留，不用它统领现行知识图。

此外，“结构即鉴定”“压片定种”（`:14`、`:37`）也过强。部分曲霉复合群内的形态特征重叠，形态观察并不总能可靠区分到种。[5] 宜改为“结构提供鉴别线索”，明确鉴定层级可能止于属或复合群。

**判定：术语错配、分类框架过时；种级结论还需降级。**

### R4. CLSI与EUCAST的解释类别不能放在一起却只给一套定义

**定位：**`img/glossary-ast-terms.svg:37`、`:43`～`:44`、`:65`～`:69`及`:3`的描述文本。

图中写“I 中介”，底部却并列CLSI/EUCAST；这样容易让初学者以为两套体系对I的含义相同。EUCAST的I是“Susceptible, increased exposure”，即增加暴露时敏感，并非直接沿用CLSI的中介含义。[25]

另一个问题在 `desc`：“SDD＝剂量依赖敏感（高剂量方案下可报敏感……）”。M100 Ed36将SDD作为独立解释类别定义，含义是敏感性取决于所采用的给药方案；不宜用“可报敏感”模糊SDD与S的报告类别。[28]

**判定：体系限定缺失，且隐藏描述有误导风险。**不能只改画面而漏掉`desc`。

**建议：**

- 图中明确标注“CLSI解释类别示意”；或者用小型对照区分别说明两体系中的I。
- SDD写为“剂量依赖敏感，按相应方案与标准解释”，保留其独立类别，不写成自动改报S。
- 给药方案、菌种—药物折点等具体内容继续由经过核验的专门条目承担，不复制进概念图。

本条已回查M100原始PDF第40页、印刷第8页的定义，不是从转换件的折点矩阵推断。

## 三、🟡 应提高严谨性的五个方面

### Y1. WT不是“完全没有耐药机制”

**定位：**`img/glossary-ast-terms.svg:52`写“WT野生型（左峰＝无耐药机制群体）”。

WT/ECOFF针对特定微生物与药物组合，讨论的是没有可表型检出的获得性耐药机制的群体边界；删掉“获得性”“可表型检出”和组合范围，会把概念扩大成“对所有药都没有耐药机制”。[30]

**建议表达：**“该菌种—药物组合的野生型分布；未见可表型检出的获得性耐药。”

原图 `:54`～`:55`的“ECV≠临床折点，不能据ECV发S/I/R报告”应保留并突出。需要完善的是术语的限定，不是推翻这条正确的边界提醒。

### Y2. 抗体曲线应是典型示意，不是通用的感染时间判定器

**定位：**`img/glossary-virus-serology.svg:52`、`:57`～`:59`。

“IgM早峰＝新近”“双份血清IgG升高＝确诊依据”若没有病原、检测方法和临床背景限定，很容易被当成所有感染通用的规则。例如CDC明确指出，CMV的IgM可见于继发感染，不能单独诊断原发感染；IgG阳性也不能单独确定感染发生时间。[26]

**判定：典型示意可以保留，等号式结论过强。**原图 `:62`已有“IgM阳性≠确诊”的提醒，不应忽略这一优点；问题在于主标签过强、限制缩在页脚，二者形成张力。

**建议表达：**将标题改为“典型初次免疫应答示意”；主标签用“常较早出现”“可持续存在”，旁注“时间与诊断意义依病原、宿主和检测方法而异”。某病种的确诊标准链接到相应条目，不塞进一张泛用抗体曲线。

### Y3. 包膜知识不能直接变成消毒等级的判断规则

**定位：**`img/glossary-structure-fungi-virus.svg:97`、`:103`，包括“裸病毒需高水平消毒”“包膜有无决定消毒等级与传播途径”。

消毒/灭菌要求不能仅由病毒是否有包膜决定。CDC的医疗器械处理框架还依据器械用途及接触部位，将关键、半关键和非关键器械分别管理。[27]

**建议：**保留“包膜结构与对环境、理化因素的敏感性有关”的基础概念，删除直接推导固定消毒等级的说法。具体消毒要求回到处理对象、产品说明和现行规范；传播方式另作专题，不由一个结构特征代替整套传播知识。

**判定：过度概括，需要拆开“结构知识”和“实际管理规则”。**本轮不提供消毒操作配方或条件。

### Y4. 生物膜、耐受与持留不应被读成同一种“耐药”

**定位：**`img/resistance-biofilm.svg:12`的“耐药机制”分类与`:64`的“持留菌：代谢静止→耐受”。

原图已经使用“耐受”一词，方向值得保留；但整体挂在“耐药机制”框架下，仍缺少概念层次。共识文件区分了耐药、耐受和持留：后两者可表现为存活差异，而不伴随MIC升高。[18]

**建议：**增加一句“生物膜相关难清除不等于常规药敏必然显示耐药”；将耐药、耐受、持留作为相关但不等同的概念。也不把“代谢静止”写成所有持留现象的唯一解释。

**判定：不是整张图错误，而是有价值的概念深化。**这里只建议基础概念澄清，不展开形成或增强相关表型的实验途径。

### Y5. 鉴定方法图应说明“能回答什么”和“回答到哪一级”

**定位：**`img/media-chromagar-candida.svg:66`～`:79`；`img/test-maldi.svg:2`、`:13`、`:80`、`:96`、`:103`。

显色图已经提醒“颜色只作初筛”，质谱图也提到部分近缘对象难区分，这些应保留。更值得补的是：每种证据能支持到哪个层级，以及结果解释依赖什么条件。

例如，曲霉资料既强调复合群内形态重叠，也强调参考谱库覆盖对质谱鉴定的重要性；“画面里出现一个最高分”不应被抽象成所有系统通用的种级确认规则。[5]

**建议：**

- 显色图说明其参考的产品/资料范围，不把某一套颜色示意当作所有同类产品的标准。
- 质谱图强调“按所用系统经过验证的判读规则与谱库范围解释”，不只看候选之间的相对高低。
- 通用地分开“检测到对象”“鉴定到种”“是否导致感染”“能否指导用药”这几类问题，避免一个箭头把它们串成自动成立的结论。

**判定：属于证据边界和教学组织优化，不据此认定现有所有显色、质谱结论都错。**

## 四、我建议采用的知识图标准

### 1. 每张图回答一个问题，而不是成为一张压缩教材页

推荐的知识层次：

1. **观察层：**图里能直接看见什么。
2. **原理层：**这一现象通常怎样解释。
3. **意义层：**它支持什么判断。
4. **边界层：**仅凭它不能判断什么。

例如“看见某结构”“符合某类典型特征”“可以确认某个种”是不同强度的结论，不应用等号直接连起来。科学内容的优化，往往是把这些层次拆开，而不是再添加一排小字。

### 2. 保留限定词，慎用等号和“身份证”式口诀

建议形成编辑规则：

| 原文证据的强度 | 图内可用表达 | 不应升级成 |
|---|---|---|
| 常见、典型、多数 | 常见表现 / 典型示意 | 全部如此 |
| 可以提示、支持 | 提示 / 支持，需结合其他信息 | 即可确诊 |
| 在某类产品或体系下 | 标注产品/体系范围 | 全平台通用 |
| 某些菌株或种 | 部分 / 依菌种而异 | 整个属必然如此 |
| 形态相似但可能重叠 | 鉴别线索 / 复合群层级 | 仅看该形态就定种 |

口诀不是不能用，而是应帮助记忆正确边界，不能为了顺口删除边界。

### 3. 将概念图与规范、阈值分开维护

图片适合承载相对稳定的原理。标准体系、产品阈值、适用菌种、方法限定等容易变化的内容，应由同一份经过核验的数据源维护，并在图旁标注依据和版本。

这不是说所有数字都不能进图：**教学例值可以使用，但必须明确是例值，且与图形逻辑一致；实际判读阈值则必须有适用范围和来源。**不要让同一规则在正文、SVG文字、`desc`中手工维护三份。

### 4. 分类学更新应兼顾正确性和可检索性

现行名称作为主表达，旧名称保留为别名或历史提示；属、种、复合群、目等层级要明确。避免为了“新”而把读者熟悉的旧名全部删除，也避免继续用过时分类框架讲现代知识。

### 5. 增加“为什么不能单凭这一项下结论”的学习点

这比继续增加名单更适合医学检验教学。可以在图旁用一句短文回答：

- 有哪些常见的解释边界？
- 哪个观察只支持初筛？
- 图中的对象和结论分别处于哪个分类层级？
- 这条规则来自哪套标准、哪个版本？

不必为每个图添加复杂互动；先让学习者分清“我看到了什么”和“我能据此说什么”。

## 五、建议优先级与验收

### 第一批：应先修正文级错误，而不是先重绘

优先处理：MIC示意逻辑、厚壁孢子独有性、曲霉结构描述、CLSI/EUCAST类别限定。真菌旧分类表述同批复核。

**验收：**每一条结论均有明确来源或可复现的图内逻辑证据；图形、可见文字、`title/desc`同步，不保留互相冲突的版本。

### 第二批：统一结论强度

完善WT、抗体曲线、包膜与消毒、耐受/持留、鉴定方法局限等内容；只增加会改变读者理解的限定，避免无限扩写。

**验收：**读者不会把“典型、提示、需要进一步确认”读成“唯一、必然、已经确诊”。

### 第三批：将审查从“看着专业”变成可追溯

每个重点图至少维护：核心命题、来源、适用范围、最近复核日期、待复核事项。专业审核人最终签核；AI意见、检索命中和现有自动测试不能代替医学责任人的确认。

**本轮仍待后续专门核验：**其余图片的逐句科学准确性，以及涉及标准版本、产品特异性阈值、具体方法条件的内容。本报告不提供这些参数的替代值，也不将未检查部分默认为正确。
