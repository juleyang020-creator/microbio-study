## 观察与建议（未改，供产品决策）

1. **视觉模型审查不可靠**：GLM-4.6V 对截图多次回答"无问题"，但把被横滚截断的标签念成完整文本（"遗传与变"→认为完整、"国名速查"→"国名速查"照抄错字）。本次所有结论以 DOM 量测为准；今后 UI 审查建议保持"截图粗筛 + DOM 实测定案"的双轨。
2. **触控目标偏小（手机端普遍）**：详情页正文内链（药名/术语链接 h≈21px）、关联词条 chip（h≈28px）、折点表药名链接（h≈32px）均低于 44px 推荐值。数量极大（铜绿一页就 100+ 个），全量放大 2 倍会显著增加页面高度——建议只给 `fav-star`（收藏星，h20px）单独加触控区（`padding` 扩展不改视觉大小），正文内链维持现状。
3. **320px 顶栏占 225px（约 1/3 屏）**：属已知取舍（CSS 注释记录 wrap 方案更糟：顶栏会到 300px+）。若未来要优化，方向是窄屏把两块导航板收进抽屉，属结构性改动，建议单独排期。
4. **无深色模式**：`prefers-color-scheme` 无匹配。PWA 手机端夜间使用（检验科夜班场景）会刺眼。CSS 变量体系已就绪（`--bg/--surface/--ink` 等），补一套暗色变量成本不高，可作为后续增强。
5. **favicon.ico 缺失**：仓库无 `/favicon.ico`，控制台有一条 404。manifest 图标链齐全，仅直开浏览器标签页无图标，建议补一个。
